extract ()

The extract function is used to extract several different types of compressed archive files. It uses a for loop that first goes through every archive file name the user passes in as an argument. In the loop, there is an if statement to check if the current argument is a real file, using -f $archive. If it is a valid file, a case statement is used to check the file extension and run the correct command to extract. For example, .zip files use unzip $archive, .tar files use tar xvf $archive, and .gz files use gunzip $archive. If the extension does not match any known file type, then the default case prints that it does not know how to extract the file. If the argument is not a real file, the else branch prints that it is not a valid file.

up ()

The up function is used here to move up a chosen number of parent directories in a single command. It creates a local variable named d, and sets a limit equal to the first argument given by the user. A for loop is then used to iterate from i = 1 up to the limit value, and each time the loop runs, it adds /.. to d, which builds a relative path upward. After the loop, sed is used to remove the first slash from the path, making a valid relative path like “../..”, instead of “/../..”. Then, an if statement checks whether d is empty. If empty, the function sets d to “..”, which ensures that the function moves up one directory by default. Then, cd $d is called, which moves the specified number of directories upward.
